# 0.96.0 — Minecraft 26.3 port

First build for **Minecraft 26.3** (the new year-based versioning; internally
Java Edition 1.26.x). This is a full port, not a version bump.

## What changed under the hood

- **Mojang official mappings**, not Yarn. 26.1+ ships unobfuscated and Fabric
  discontinued Yarn, so the whole tree was migrated (`migrateMappings`) and the
  remaining 1.21.11→26.3 vanilla changes fixed.
- Build: Fabric Loom `net.fabricmc.fabric-loom` 1.18.4, Fabric Loader 0.19.5,
  Fabric API 0.162.0+26.3, **Java 25**, single-project build (the old
  multi-version preprocessor is gone).
- Libraries ship inside the jar (tungsten, py4j, Jackson, nether-pathfinder,
  Cloth Config).

## New in this release

- **In-game settings screen** (Cloth Config). Keybind **K** → "UnionClef
  Settings"; rebindable under Options → Controls → Miscellaneous. Exposes the
  mod's general/HUD, movement & combat, resource, survival, inventory/crafting,
  session/automation and agent-bridge settings. Saving writes
  `altoclef_settings.json` exactly as before.

## Ported back (was dropped during the initial 26.3 pass)

- Chat command **tab-completion + highlighting** for `@commands`
  (`ChatInputSuggestorMixin`, tungsten `MixinChatInputSuggestor` +
  `MixinSuggestionWindow`).
- Furnace **fuel burn-time** resolution (`ItemHelper`).
- ~16 Mixin hooks re-targeted to their 26.3 method names — chat read, chat send,
  screen-open, block interact, entity attack, chunk load/unload, container slot
  changes, block placement, damage events, overlay messages, FPS-throttle bypass,
  item-entity pickup, option changes.

## Testing

- `gradlew build` green for altoclef + tungsten.
- Client boots on 26.3 (PrismLauncher, Fabric Loader 0.19.5, Fabric API
  0.162.0+26.3, alongside Sodium/Lithium/EntityCulling/ImmediatelyFast).

## Known

- Behaviour (pathing, combat, water, mining) has not been play-tested on 26.3 yet.
- `ItemHelper` resolves referenced datapack `COOKING_TIME_*` fuels to their
  furnace (normal) burn time, since a client has no server `LootContext`; the
  smoker/blast-furnace ×2 factor is not applied.
